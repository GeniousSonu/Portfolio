## ✨ Website Architecture & Features

- ⚡ **Next.js 16 + React 19 App Router** — High-performance SSR and static generation.
- 🔤 **Geist Font Integration** — Self-hosted Next.js Google font for perfect typography hierarchy.
- 🤖 **Full LLM & Search Engine Indexing** — `llms.txt`, `ai.txt`, `sitemap.xml`, `robots.txt`, and rich Schema.org (`Person`, `WebSite`, `ProfilePage`, `Occupation`, `Patent`).
- 🎬 **Custom GSAP Animations** — Staggered reveals, text plugins, scroll triggers, magnetic button physics.
- 🌐 **Interactive WebGL 3D Globe** — Powered by Three.js and Globe.gl showing international client connections.
- 📬 **Functional Contact Form** — Interactive client-side mailto prefill generator + Netlify Forms integration.
- 💚 **Canvas Matrix Rain Footer** — High-FPS customized Japanese/hex matrix character waterfall.
- 📱 **Fully Responsive** — Mobile-first optimization from 320px screens up to 4K displays.

## 🛠️ Tech Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | [Next.js](https://nextjs.org/) 16 | React SSR, metadata, routing |
| **UI Model** | [React](https://react.dev/) 19 | Declarative components & state |
| **Typography** | Geist (`next/font/google`) | Self-hosted sans and mono typography |
| **Animations** | [GSAP](https://gsap.com/) 3 | Motion, scroll triggers, text plugins |
| **3D Rendering** | [Globe.gl](https://globe.gl/) & [Three.js](https://threejs.org/) | WebGL interactive globe |
| **SEO & Microdata** | Schema.org JSON-LD + LLMs.txt | Machine-readable indexing |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/GeniousSonu/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
